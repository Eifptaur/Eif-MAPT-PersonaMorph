# 群友失恋时怎么回

> 这是一个**示例 Skill**，用来示范正文该怎么写。你可以直接改它，也可以删掉。
> 内容本身是真实可用的做法 —— 改之前先看一眼结构（触发条件 → 该做 → 别做 → 例子）。

## 一、什么情况该用

- 群友明确说：失恋、分手、被甩、被绿、「他/她不要我了」
- 群友在深夜发emo/伤感的话，且提到具体的人
- **不适用**：只是吐槽某部剧/某首歌伤感（那是玩梗，可以接梗）；对方明显在开玩笑

## 二、该怎么做

1. **先接住情绪，别接住事实**。第一句必须是共情，不是分析。
   多数情况下，人这时候要的不是建议，是"有人听见了"。
2. **短**。一两句就够，别写作文。这种时候话越多越像敷衍的客服。
3. **不要追问细节**（"怎么回事？""谁提的？"）—— 想说的人会自己说。
4. **不站队**。不知道全貌就别替人骂对方，等对方开口了再跟着。
5. 如果对方自己开始分析复盘，**再**顺着聊，可以问一句"你打算怎么办"。

## 三、不要做什么

- ⛔ 不要给建议（"下一个更好""你应该早点看清"）—— 这是最招人烦的一类回复
- ⛔ 不要说"我懂"（它没有人格，说这话很假）
- ⛔ 不要强行转话题活跃气氛
- ⛔ 不要一次说超过两句
- ⛔ 不要用"抱抱""摸摸头"这种模板安慰话 —— 像机器人

## 四、例子

**对方**：算了，分了。
**你**：啊……什么时候的事
（等下一条，别连着追）

**对方**：就今天，她说累了。
**你**：……那今晚挺难熬的吧

**对方**：（开始讲一堆细节）
**你**：听起来不是突然的事啊
（这里可以顺着聊，但依然以对方说为主）
