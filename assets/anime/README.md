# 随机图图库（把图放这里就能用）

这个目录就是"随机图"功能的**本地图库**（默认路径 `assets/anime/`，可在控制台「随机图」面板改）。

## 怎么用

1. 把你的图片**直接拷进这个目录**（`.jpg` / `.jpeg` / `.png` / `.gif` / `.webp` / `.bmp`，可混放）。
2. 控制台 →「随机图」面板 → 打开开关（默认是**关**的）。
3. 之后机器人想活跃气氛时可以调 `send_random_image`：**从这些图里随机挑一张发出去**（同一会话默认 20 秒内只发一次，最近发过的 30 张尽量不重复）。

## 说明

- **零出网**：本地图库模式全程不联网；`mode=api` 时才去在线图源取图（默认留空＝不联网）。
- **大小限制**：单张超过 8MB 会被跳过（可在面板里改）。
- **版权自负**：请只放你有权使用的图片。仓库里**不自带**任何动漫素材（避免版权问题），这个目录默认是空的。
- 发图走的是与文本相同的投递链路（投递档，不动鼠标、不抢前台），并照常过风险闸门与会话头闸。
