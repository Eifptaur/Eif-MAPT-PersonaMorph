W7 余项收口：版本能力矩阵面板 + 版本门接线（没实测过的版本对默认暂停发送）

背景：`version_matrix.gate()` 早就会给出「没实测记录」，但**没有任何地方问它** —— 用户升级微信后
发送照旧跑，出问题才发现这版没验证过。本轮把这条接上。

- 新增 agent/version_gate.py（三级：ok 实测过放行 / warn 未实测默认暂停 / 允许本次会话临时放行）：
  allow_session() 只作用于本进程内存（**不落盘、不写配置**，重启重新拦），check() 返回可读理由。
  已接进三个发送入口（send_text / send_image / send_file_posted）—— 未放行时返回可读原因，不静默降级。
  注意：临时放行优先于「读不到微信版本」分支（否则微信没跑时点放行会被忽略）。
- webui：/api/status 带 version_gate，新增 /api/version/allow（临时放行）。
- 控制台：新增「版本能力矩阵」页（当前版本对 + 逐能力状态 + 一行摘要）与版本门横幅 +
  「本次允许发送」按钮；横幅文案明写只对本次运行有效。
- 判据：scripts/version_gate_selftest.py 19/0（默认拦 / 放行后仍为 warn 不是 ok / clear 后重拦 /
  放行不落盘 / 三个 send 入口都问门 / 控制台面板与端点与按钮）；回归 selftest.py 55/55。
  README 与使用说明同步。
