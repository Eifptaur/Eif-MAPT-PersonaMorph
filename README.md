# 群相（Persona Morph）
> **非官方产品**：本项目与腾讯无关，未获腾讯授权、认可或赞助；「微信」是腾讯的商标，本项目中仅用于说明兼容对象。请勿将本项目用于任何违反微信协议或法律法规的用途。

Windows 微信群聊机器人：监听微信群消息，按设定人设回复；本地运行，接入你的模型 API 账号。

- 运行环境：Windows 10/11，微信 4.1.13（UIA 自动化，无注入、不改微信文件、不碰协议）
- 部署方式：一键启动（自动配置 Python 与依赖，无需手动安装环境）
- 发布包：`PersonaMorph-vbeta2.zip`（源码包，联网安装）；`PersonaMorph-offline-vbeta2.zip`（离线包，含依赖与绿色 Python，无网可装）
- 仅供学习交流，请阅读文末「风险提示」

## 功能一览

- **群友印象 + 上次聊过**：机器人对每位群友除了"他是谁"（印象），还会带一行「上次聊过「…」（X 前）」——这行是**从本机消息库现读**的（不花 token、不凭空编），并且**本轮正在回答的那几条不算"上次"**；只有本轮发言的新群友不会出现这行。

- **语音转文字（本地离线，默认关）**：群友发来的语音可以转成文字再交给模型理解。链路＝微信语音 `.silk` → `pilk` 解码 → WAV → **Windows 内置语音识别**（SAPI 文件听写，中文识别器随系统有）；**全程本机、音频不出网**。缺解码器/识别引擎时，控制台面板会**明确写出缺哪一环与怎么补**，不会假装识别过（判据 `scripts\voice_selftest.py` 含"TTS→SILK→文本"的闭环自证）。
- **视频/文件与链接（能力 C）**：群友发的**视频/文件**可以下载到本机（`download_media`，落在 `media/video`、`media/file`）；**链接**不用下载——直接把链接发出去是**纯后台**投递。**转发视频/文件默认关闭**：这一步必须过一次系统「选择文件」对话框、会**短暂抢一次前台**（与"全程后台不抢前台"的最高目标冲突）⇒ 想用要显式打开 `send.file_forward_optin`，控制台与模型都会照实说明这件事。
- **语音回复（TTS，默认关）**：让机器人**用语音回一句**——文字经**本机 Windows 内置语音合成**（零下载）转成音频再发出去；有 ffmpeg 就转 mp3，没有就发 wav。⚠️ **当前形态是"音频文件"，不是微信语音条**：微信 PC 没有"把任意音频发成语音条"的接口（要真语音条得用虚拟声卡 + 录音按钮，属待评估项）。合成全程本机、合成内容不出网。控制台**「语音回复」面板**可以看**实测**引擎/声音状态、切开关与音色语速格式，并用「试听一句」在本机合成一条示例（**只合成、不发送**）。
- **自定义工具（声明式 HTTP，默认关）**：把 `.json` 清单丢进 `tools.d/`，在控制台「工具与插件」里**勾选**就能给模型用。**只发 HTTP、不执行本地代码**；域名白名单必填，内网/本机地址永远拒绝；参数必须是合法 JSON Schema；坏清单会在面板里逐条报出来（不静默）。**怎么写、怎么加：控制台 →「工具与插件」→「怎么加工具」有应用内引导（三步 + 可复制模板 + 一键生成模板文件 + 打开目录 + 排错对照）；离线说明另见 [`tools.d/README.md`](tools.d/README.md)（中英双语）**。同时开始统计**每个工具的调用次数**（内置与自定义都算），一眼看出哪些只是摆设。
- **微信接入**：监听目标群消息，被 @ 或命中关键词时回复；支持发送文字、引用、拍一拍、表情收藏/发送、朋友圈查看（部分为模拟真人操作，需微信界面配合）
- **人设系统**：内置角色库（游戏/动漫/名著/历史等人物，可筛选、按分排序）；应用任意人设为机器人；支持自定义角色卡
- **评分与补足**：角色卡五维模型评分（风格/贴合/一致/自然/完整，百分位精度）；模型补足（按角色原话重写，分数上升才保留）
- **记忆**：群成员印象自动记录；记忆页查看/修改/删除；支持关机时把本次对话总结为印象
- **学习**：金句种子库（收藏高热度话术）、行为档推荐（参与度+表情包档位）
- **工具集**：联网搜索、图片识别、多轮对话、消息发送队列、API 中转站支持（OpenAI 兼容任意厂商）
- **用量与计费**：控制台实时统计会话/token/成本（今日/周期/累计），每日明细日历；计费日志可勾选删除
- **检测中心**：代码检测（48 项，含依赖核对）、点击测试（环境/点击/微信界面自动化 55 项，全程序内完成、不碰鼠标）
- **控制台**：本地 Web 界面（端口 3210），所有可调项目（API、模型、人设、行为、记忆、发送限制、联网搜索、界面设置等）均可在界面中调节并保存生效。内含**「媒体与语音」面板**（随机图 / 语音转文字 / 视频·文件·链接 三项能力的开关、**实测引擎状态**、空状态与缺失态提示，「测试引擎」按钮会当场跑一遍本机语音链路）与**「版本能力矩阵」面板**（微信版本 × 适配层版本的逐项实测状态 + 版本门）。

## 快速开始

### 方式一：源码包（联网安装）

1. 解压 `PersonaMorph-vbeta2.zip` 到任意目录（路径不要有中文与空格最好）；
2. 双击 **「一键启动.exe」**——自动：检查/下载 Python → 安装缺失依赖 → 环境自检 → 启动机器人并打开控制台；
3. 浏览器自动打开 `http://127.0.0.1:3210/`（若未自动打开，手动访问该地址并用日志中提示的口令登录）；
4. 首次使用：到「模型 API」页填 Base URL（默认 DeepSeek 官方 `https://api.deepseek.com/v1`）与 API Key →「测试 API 连通」→「保存」；
5. 到「微信」页点「检测群聊并勾选」选择要监听的群 →「保存设置」；
6. 顶栏点「恢复」开始监听。

### 方式二：离线包（无网电脑安装）

1. 解压 `PersonaMorph-offline-vbeta2.zip` 到目标电脑（离线包已含绿色 Python 与全部依赖）；
2. 若未安装微信：安装包内含微信 4.1.13 安装程序（`offline/wechat/`）；
3. 双击 **「一键启动.exe」**——自动解压绿色 Python、离线安装依赖、自检、启动并打开控制台；
4. 后续同「方式一」第 4~6 步（配置 API、勾选群、恢复）。

> 日常使用请用「一键启动.exe」（图形启动器，双击即启；旧系统可用「一键启动.exe」兜底）；关闭请用「一键关闭.exe」（结束机器人/看门狗/安装器等全部残留进程）；开机自启=管理员运行 `scripts\开机自启.bat`。
> 离线包与源码包用法不同，请勿混用说明：详见《使用说明.md》与 `offline\README-离线包.txt`。

## 目录结构（简述）

- `scripts\persona_morph.py` 主程序；`agent\` 核心模块；`scripts\` 辅助脚本（启动/停止/看门狗/自检/依赖安装）
- `一键启动.exe` / `一键关闭.exe`；`offline\` 离线依赖包
- `data\` `logs\` `media\` 运行时数据（含隐私与 API Key 相关，请勿外发）
- `config.json` 你的配置（含 API Key，**不要上传/外发**）；`config.example.json` 配置模板

## 常用设置说明（控制台）

- **版本能力矩阵与版本门**：控制台新增「版本能力矩阵」页，列出当前「微信版本 × 适配层版本」下每个能力的实测状态。**没有实测记录的版本对，发送前会被版本门拦下**（默认暂停自动发送，避免升级微信后照旧跑出事）；点「本次允许发送」可临时放行——**只对本次运行有效、不写进配置，重启重新拦**。

- **历史兜底条数**（`store.past_floor_count`，默认 8，0=关闭）：时间窗（`store.past_window_min`，默认 30 分钟）之外**至少保留最近 N 条**，并插入「这些是更早的历史、不是本轮要回答的内容」的提醒。为什么需要：群里长时间静默后突然被触发时，只按时间窗取会一条历史都取不到（模型被误导成「第一次参与这个会话」）——兜底保证它永远看得到上文。

| 设置项 | 位置 | 说明 |
|---|---|---|
| API 地址/Key/模型 | 模型 API | 填你的厂商；支持中转站地址 |
| 监听群 | 微信 | 勾选目标群白名单 |
| 人设 | 人设与响应 | 选内置角色或自定义；评分/补足在此页 |
| 参与度/表情 | 人设与响应 | 按角色推荐行为档 |
| 发送限制 | 发送限制 | 每分钟上限/引用概率等 |
| 联网搜索 | 联网搜索 | 开关与搜索引擎配置 |
| 记忆 | 记忆 | 印象管理/共享/关机总结开关 |
| 界面适配 | 界面适配 | 缩放/主题/背景/光标（内置默认样式，支持上传自定义图片） |

## 权限与红线（务必先读）

### 它需要哪些能力、用来做什么

| 能力 | 具体动作 | 用途 | 边界 |
|---|---|---|---|
| 读微信本地数据 | 读 `WeChat Files` 下的本地数据库（消息/联系人/群） | 判断"谁说了什么"、拼上下文 | **只读本机、只读你自己的账号**；不做云端同步 |
| 数据库解密密钥 | 从本机微信进程内存里读取密钥，用来解密上面那些库 | 上面的读取必需 | **密钥永不出网**：不写日志、不进诊断包、不上传任何服务器 |
| 模拟操作微信 | 以后台消息注入为主（投窗口消息，不动鼠标、不抢前台）；必要时 UIA / 真实键鼠兜底 | 发消息、引用、拍一拍、朋友圈等 | **不注入 DLL、不 hook、不写微信进程内存、不改微信文件、不装驱动** |
| 本地控制台 | `http://127.0.0.1:3210`，需访问口令；**口令为空时拒绝一切请求** | 配置与监控 | **只绑回环**；`server.host` 写成别的地址会被强制改回 `127.0.0.1` |
| 出网 | 只发给你自己配置的模型 API（以及可选的搜索接口） | 生成回复 | 发送前本地脱敏（手机号/身份证/银行卡/地址），只送本轮必要片段 |
| 出网（随机图·在线图源） | 只在 `image_reply.mode=api/online` 时访问公开图源接口 | 取一张图再发 | **SSRF 闸门默认全开**：图源指向内网/环回/链路本地地址一律拒绝；只有自建本机图库服务才需要开 `security.allow_private_image_hosts`（**故意不做控制台开关**，要放开请手改 `config.json`） |
| 语音转文字 | 读本机微信语音文件（`.silk`）→ 本地解码 → **Windows 内置识别** | 让机器人"听懂"语音消息 | **音频不出网、不落云**；解码器 `pilk` 是**可选第三方依赖（GPL-3.0，不随本项目分发，需自行 `pip install pilk`）**，不用它就只是"不支持语音"而不是报错 |

### 我们不做的事（红线，写死在代码与判据里）

1. **不做成品分发**：只发布源码与离线依赖，不提供"装机即用"的分发包（《刑法》285 条 3 款对"提供专门工具"有独立门槛）；
2. **不做营销群发**：默认带任务层闸门——同一内容在短时间内发给多个不同会话会被判定为群发并拦下；
3. **不做群控 / 加粉 / 自动换号 / 代理池 / 绕过风控**，也不写这类教程（这是"专门性"与"规避性"的分界线）；
4. **不读群成员列表、不导出他人数据**：群里其他人的信息不落库、不外传；
5. **不把 AI 回复伪装成真人**：用第三方模型时请保留可识别的标识（建议在会话固定位置标注，不必逐条加）；
6. **不上传任何来自微信的数据或密钥、不采集设备指纹**（对照：某些同类工具会把你的微信数据库密钥派生物上传到它自己的服务器做授权校验，我们不这么做）。

### 账号风险与免责

速度/频率类旋钮（每分钟·每小时·每天上限、夜间静默、群发判定阈值）**默认全部不限或关闭**，由你自己按账号情况在控制台「风险闸门」里设置。微信官方协议禁止自动化程序，**封号风险由使用者自行评估与承担**；程序内的风险闸门只做内容与任务层的兜底，**不能**免除协议风险。建议：用小号、控制频率、不群发不刷数据。

## 风险提示

微信官方协议禁止非官方客户端/自动化程序。本项目以后台消息注入为主（不注入、不改微信文件、目前主要不动鼠标），风险较低但非零；频率与静默**默认不设限、由你自己把控**（控制台「风险闸门」）。建议：使用小号、控制频率、不群发不刷数据。**是否使用、以及账号风险，请自行评估与承担**（详见上一节「权限与红线」）。
