# 群相灵（Persona Morph）
> **非官方产品**：本项目与腾讯无关，未获腾讯授权、认可或赞助；「微信」是腾讯的商标，本项目中仅用于说明兼容对象。请勿将本项目用于任何违反微信协议或法律法规的用途。

Windows 微信群聊机器人：监听微信群消息，按设定人设回复；本地运行，接入你的模型 API 账号。

- 运行环境：Windows 10/11，微信 4.1.13（UIA 自动化，无注入、不改微信文件、不碰协议）
- 部署方式：一键启动（自动配置 Python 与依赖，无需手动安装环境）
- 发布包：`PersonaMorph-vbeta2.zip`（源码包，联网安装）；`PersonaMorph-offline-vbeta2.zip`（离线包，含依赖与绿色 Python，无网可装）
- 仅供学习交流，请阅读文末「风险提示」

## 功能一览

- **微信接入**：监听目标群消息，被 @ 或命中关键词时回复；支持发送文字、引用、拍一拍、表情收藏/发送、朋友圈查看（部分为模拟真人操作，需微信界面配合）
- **人设系统**：内置角色库（游戏/动漫/名著/历史等人物，可筛选、按分排序）；应用任意人设为机器人；支持自定义角色卡
- **评分与补足**：角色卡五维模型评分（风格/贴合/一致/自然/完整，百分位精度）；模型补足（按角色原话重写，分数上升才保留）
- **记忆**：群成员印象自动记录；记忆页查看/修改/删除；支持关机时把本次对话总结为印象
- **学习**：金句种子库（收藏高热度话术）、行为档推荐（参与度+表情包档位）
- **工具集**：联网搜索、图片识别、多轮对话、消息发送队列、API 中转站支持（OpenAI 兼容任意厂商）
- **用量与计费**：控制台实时统计会话/token/成本（今日/周期/累计），每日明细日历；计费日志可勾选删除
- **检测中心**：代码检测（48 项，含依赖核对）、鼠标操作检测（环境/点击/微信界面自动化 55 项）
- **控制台**：本地 Web 界面（端口 3210），所有可调项目（API、模型、人设、行为、记忆、发送限制、联网搜索、界面设置等）均可在界面中调节并保存生效

## 快速开始

### 方式一：源码包（联网安装）

1. 解压 `PersonaMorph-vbeta2.zip` 到任意目录（路径不要有中文与空格最好）；
2. 双击 **「一键启动.exe」**——自动：检查/下载 Python → 安装缺失依赖 → 环境自检 → 启动机器人并打开控制台；
3. 浏览器自动打开 `http://127.0.0.1:3210/`（若未自动打开，手动访问该地址并用日志中提示的口令登录）；
4. 首次使用：到「模型 API」页填 Base URL（默认 DeepSeek 官方 `https://api.deepseek.com/v1`）与 API Key →「测试 API 连通」→「保存」；
5. 到「微信」页点「检测群聊并勾选」选择要监听的群 →「保存设置」；
6. 顶栏点「恢复」开始监听。

### 方式二：离线包（无网电脑安装）

1. 解压 `PersonaMorph-offline-vbeta2.zip` 到目标电脑（离线包已含绿色 Python 与全部依赖）；
2. 若未安装微信：安装包内含微信 4.1.13 安装程序（`offline/wechat/`）；
3. 双击 **「一键启动.exe」**——自动解压绿色 Python、离线安装依赖、自检、启动并打开控制台；
4. 后续同「方式一」第 4~6 步（配置 API、勾选群、恢复）。

> 日常使用请用「一键启动.exe」（图形启动器，双击即启；旧系统可用「一键启动.exe」兜底）；关闭请用「一键关闭.exe」（结束机器人/看门狗/安装器等全部残留进程）；开机自启=管理员运行 `scripts\开机自启.bat`。
> 离线包与源码包用法不同，请勿混用说明：详见《使用说明.md》与 `offline\README-离线包.txt`。

## 目录结构（简述）

- `scripts\persona_morph.py` 主程序；`agent\` 核心模块；`scripts\` 辅助脚本（启动/停止/看门狗/自检/依赖安装）
- `一键启动.exe` / `一键关闭.exe`；`offline\` 离线依赖包
- `data\` `logs\` `media\` 运行时数据（含隐私与 API Key 相关，请勿外发）
- `config.json` 你的配置（含 API Key，**不要上传/外发**）；`config.example.json` 配置模板

## 权限与红线（务必先读）

### 它需要哪些能力、用来做什么

| 能力 | 具体动作 | 用途 | 边界 |
|---|---|---|---|
| 读微信本地数据 | 读 `WeChat Files` 下的本地数据库（消息/联系人/群） | 判断"谁说了什么"、拼上下文 | **只读本机、只读你自己的账号**；不做云端同步 |
| 数据库解密密钥 | 从本机微信进程内存里读取密钥，用来解密上面那些库 | 上面的读取必需 | **密钥永不出网**：不写日志、不进诊断包、不上传任何服务器 |
| 模拟操作微信 | 以后台消息注入为主（投窗口消息，不动鼠标、不抢前台）；必要时 UIA / 真实键鼠兜底 | 发消息、引用、拍一拍、朋友圈等 | **不注入 DLL、不 hook、不写微信进程内存、不改微信文件、不装驱动** |
| 本地控制台 | `http://127.0.0.1:3210`，需访问口令；**口令为空时拒绝一切请求** | 配置与监控 | **只绑回环**；`server.host` 写成别的地址会被强制改回 `127.0.0.1` |
| 出网 | 只发给你自己配置的模型 API（以及可选的搜索接口） | 生成回复 | 发送前本地脱敏（手机号/身份证/银行卡/地址），只送本轮必要片段 |

### 我们不做的事（红线，写死在代码与判据里）

1. **不做成品分发**：只发布源码与离线依赖，不提供"装机即用"的分发包（《刑法》285 条 3 款对"提供专门工具"有独立门槛）；
2. **不做营销群发**：默认带任务层闸门——同一内容在短时间内发给多个不同会话会被判定为群发并拦下；
3. **不做群控 / 加粉 / 自动换号 / 代理池 / 绕过风控**，也不写这类教程（这是"专门性"与"规避性"的分界线）；
4. **不读群成员列表、不导出他人数据**：群里其他人的信息不落库、不外传；
5. **不把 AI 回复伪装成真人**：用第三方模型时请保留可识别的标识（建议在会话固定位置标注，不必逐条加）；
6. **不上传任何来自微信的数据或密钥、不采集设备指纹**（对照：某些同类工具会把你的微信数据库密钥派生物上传到它自己的服务器做授权校验，我们不这么做）。

### 账号风险与免责

速度/频率类旋钮（每分钟·每小时·每天上限、夜间静默、群发判定阈值）**默认全部不限或关闭**，由你自己按账号情况在控制台「风险闸门」里设置。微信官方协议禁止自动化程序，**封号风险由使用者自行评估与承担**；程序内的风险闸门只做内容与任务层的兜底，**不能**免除协议风险。建议：用小号、控制频率、不群发不刷数据。
