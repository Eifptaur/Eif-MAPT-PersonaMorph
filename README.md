# 群相（Persona Morph）
> **非官方产品**：本项目与腾讯无关，未获腾讯授权、认可或赞助；「微信」是腾讯的商标，本项目中仅用于说明兼容对象。请勿将本项目用于任何违反微信协议或法律法规的用途。

Windows 微信群聊机器人：监听微信群消息，按设定人设回复；本地运行，接入你的模型 API 账号。

- 运行环境：Windows 10/11（实测 Win10 22H2 与 Win11），微信 4.x（本机实测 4.1.15.8；跨机实测 4.1.13.65）
- 操作方式：**后台消息投递为主**——投窗口消息给微信，**不动鼠标、不要求微信窗口可见**（最小化与被遮挡时也能干；可能短暂置前（2026-09-18 本机实测：发文字约 1 秒｜切会话 3~7 秒｜切会话失败重试可达约 15 秒），随后自动还回）；UIA 与真实键鼠只作兜底，**真鼠标兜底默认关、要显式开启**
- 部署方式：一键启动（自动配置 Python 与依赖，无需手动安装环境），首次运行需要联网
- 发布包：`群相-在线包-<日期>.zip`（源码包，联网安装）
- 仅供学习交流，请阅读文末「风险提示」

## 怎么用（一步步照做就行）

> 这一节是**操作说明书**：每个功能都写清「在哪儿点、填什么、会看到什么」。所有设置都在本机控制台里（端口 3210，双击「一键启动.exe」会自己打开）。

### 第 0 步：装好之后先做这三件事

1. **填模型**：控制台 →「模型 API」→ 填 Base URL 与 API Key（用 DeepSeek 官方就填 `https://api.deepseek.com/v1`）→ 点「测试 API 连通」→「保存」。**不填这个它不会说话。**
2. **接上微信**：控制台 →「微信」面板 → 最上面那段「接入诊断」应当几行全绿（依赖装齐 / 微信进程 / 微信版本 / 打开消息库 / 数据库密钥）。**哪一行是「卡住」，就照那一行写的做**。最常见的两种：
   - 写着「打不开消息库」⇒ 多半是微信的聊天文件不在默认位置：在微信里看「设置 → 文件管理 → 微信文件默认保存位置」，把那个目录填到本面板的「数据库目录」；
   - 写着「微信没在运行」⇒ 先把微信开起来并登录。
3. **选群、开监听**：同一面板点「检测群聊并勾选」→ 勾上你要它参与的群（**一个都不勾＝所有群都参与**）→「保存设置」→ 回顶栏点「恢复」开始监听。**默认是暂停状态**，不点「恢复」它只看不说。

### 让它回话：什么时候回、多爱说话

- 「微信」面板的**群白名单**决定"管哪些群"；右边还有个输入框可以**手打群名回车添加**（列表读不到时也能用）。
- 「人设与响应」面板的**响应档位**决定"多爱说话"：1 档几乎不主动、4 档逢聊必接。**被 @ 到、或有人引用它的话，任何档位都会回。**
- 只想让它在**群里被 @ 或引用**时才回（主人档）：同面板选「只在群里 @ 我或引用我时回」，并把你自己的号登记进「我的其他账号（大号）」。
- **指令白名单**：只有在名单里的人能用 `@机器人 禁言 30分钟` 这类指令；**留空＝谁都不能下指令**。

### 换人设 / 自己写角色

- 「人设与响应」→ 角色库里按分区筛选、按评分排序 → 点「应用」换人设。
- 自己写：同面板的「自定义角色卡」。写完可以点「评分」看五维得分；分低就点「补足」让模型按角色原话重写（**只有分数上升才保留**）。

### 记忆：它记得谁、记得什么

- 「记忆」面板：看 / 改 / 删每位群友的印象，可以按会话或按条屏蔽存档；**删除是真删**（删掉之后不会再被读出来）。
- 「记忆共享」：让不同群之间共享印象（默认不共享）。「关机时总结」：退出时把本次对话总结成印象。
- 「记忆图谱」：本机生成、零 token，一眼看清谁和谁聊过什么。

### 让它发东西（每条操作的后台程度都写在「版本能力矩阵」里）

| 想发的 | 怎么触发 | 后台程度 |
|---|---|---|
| 文字 | 群友 @ 它 / 命中关键词 | 全程后台（不动鼠标、不要求窗口可见） |
| 图片 / 文件 | 让它调用工具（`send_image` / `send_file` 等） | 全程后台 |
| 收藏的表情 | `send_emoji`（先在群里"收藏"表情） | 全程后台 |
| 语音回复（音频文件） | 「语音回复」面板开开关、选音色；点「试听一句」**只在本机合成、不发送** | 全程后台 |
| 拍一拍 / 引用某条消息 | @ 它，或让它引用 | 全程后台 |
| 转发群友发来的视频/文件 | 需显式打开 `send.file_forward_optin` | ⚠️ 会短暂抢一次前台（要过系统「选择文件」框） |
| 朋友圈查看 / 点赞评论 | 「微信」面板里对应开关 | 点赞评论走真实鼠标，默认关 |

> 这张表不是宣传口径：控制台「版本能力矩阵」页会把**每条操作**在当前「微信版本 × 适配层版本」下是"全程后台 / 后台优先 / 真鼠标"逐条列清楚，并说明没实测过的版本对会被版本门拦一下。

### 定时提醒与节假日问候

- 「定时提醒」：可以让它在**当前会话**到点提醒（结构上没有"群发"这个口子）。
- 「节假日问候」：默认只在对话里提一句；想让它**主动**发，要选 `active` 并填**问候白名单**——不填就不主动发。

### B 站、视频与生图

- 发个 B 站链接给它：能解析标题/简介/字幕，也能"听"（下载音频 → 本机识别）；
- 群友发来的视频：能抽几帧交给视觉模型看，也能"听"视频里的说话——**都走随包自带的 ffmpeg，不需要你另装**；
- 生图 / AI 视频：默认关；开了之后它会自己探本机在跑的 ComfyUI 一类服务，探到就用。

### 花了多少钱、用了多少量

- 顶栏「余额」「今日用」＋「用量与计费」面板：今日 / 周期 / 累计的 token 与成本、每日明细日历。
- **不想被别人看到余额**：顶栏余额旁边的「显示」小按钮 → **照实显示 / 隐藏 / 改成你填的数字**（例如 `8888.88`）。**只改界面上的数字，真实余额一点都不动。**

### 危险操作与限制

- 「风险闸门」：每分钟 / 每小时 / 每天上限、夜间静默、群发判定阈值——**默认全部不限**，按你自己账号的情况填。
- 「发送限制」：引用概率、同内容重复保护等。
- 面板上凡是标着"要显式开启"的能力（真鼠标兜底、转发文件、语音回复…），**默认都是关的**，开了也会如实说明代价。

### 出问题怎么办（按这个顺序试）

1. **微信连不上**：看「微信」面板那段逐步诊断，**哪一行是「卡住」就照那行写的做**；
2. **一键盘不通**：双击「一键检验（生成报告）.cmd」，它跑一遍并把报告写到 `报告\` 下 —— **把那份报告发给我们**（不含密钥、也不含聊天内容）；
3. **点「一键关闭」没关干净**：新版已改成"先收看看门狗再收本体 + 只收本程序目录里的进程 + 如实列出没关掉的"；也可以用 `一键关闭.exe --probe %TEMP%\x.txt`，**只列会关谁、不动手**；
4. **更新检查报「拉不到更新源」**：程序会自动换源重试（官方 + 国内镜像）；仍不行说明这台机器到 GitHub 的线路不通，换个网络或手动下载；
5. **日志在哪**：主日志 `data\runtime.log`；启动与收尾在 `logs\persona_morph.log`；一键启动的过程在 `logs\onestart.log`。

### 日常操作

- **启动**：双击「一键启动.exe」。第一次会联网装依赖（约 100~150MB，慢网十几分钟是正常的——**窗口里能看见正在下哪个包**）。
- **关闭**：双击「一键关闭.exe」。
- **退出全屏**：按 **ESC**（或把鼠标移到屏幕最上端，顶栏滑出来后点「还原」）。
- **更新**：控制台顶部出现公告条时点「立即更新」；更早的版本点一次「一键启动」就会自动接替完成（不用自己解压）。
- **反馈**：「反馈」面板 → 选类型、写内容、点「提交」就行，其余细节都收在「更多」里。

## 功能一览

- **全程后台（本项目的核心）**：发消息、切会话、发图片/文件、发表情都走**投递**——**不动你的鼠标**，也**不要求微信窗口可见**（被别的窗口完全盖住、甚至收进任务栏都能干活）。代价如实说：投递靠"伪激活"让微信以为自己被激活，会把微信**短暂置前**，随后自动还回你原来那个窗口。**实测（2026-09-18，本机 40ms 采样）**：取 GUI / 朋友圈滚动 / 表情面板 **0 秒**、发文字约 1 秒、**切会话 3~7 秒**、**切会话失败重试可达约 15 秒**；这一段里你正在别处打字可能受影响。**一定非得走前台**的只有三项：朋友圈点赞/评论/发朋友圈、转发视频或文件那一下（系统「选择文件」对话框）、UI 标定与真鼠标兜底档（默认关）；后台档对这三项一律**跳过并说明原因**，不偷偷用真鼠标。**真鼠标兜底默认关**，要开得显式打开。哪条操作是后台、哪条还得真鼠标，控制台里有一张**逐条列明**的账，不藏。

- **群友印象 + 上次聊过**：机器人对每位群友除了"他是谁"（印象），还会带一行「上次聊过「…」（X 前）」——这行是**从本机消息库现读**的（不花 token、不凭空编），并且**本轮正在回答的那几条不算"上次"**；只有本轮发言的新群友不会出现这行。

- **语音转文字（本地离线，默认关）**：群友发来的语音可以转成文字再交给模型理解。链路＝微信语音 `.silk` → `pilk` 解码 → WAV → **Windows 内置语音识别**（SAPI 文件听写，中文识别器随系统有）；**全程本机、音频不出网**。缺解码器/识别引擎时，控制台面板会**明确写出缺哪一环与怎么补**，不会假装识别过（自检 `scripts\voice_selftest.py` 含"TTS→SILK→文本"的闭环自证）。
- **视频/文件与链接（能力 C）**：群友发的**视频/文件**可以下载到本机（`download_media`，落在 `media/video`、`media/file`）；**链接**不用下载——直接把链接发出去是**纯后台**投递。**转发视频/文件默认关闭**：这一步必须过一次系统「选择文件」对话框、会**短暂抢一次前台**（与"全程后台不打扰你"的最高目标冲突）⇒ 想用要显式打开 `send.file_forward_optin`，控制台与模型都会照实说明这件事。
- **语音回复（TTS，默认关）**：让机器人**用语音回一句**——文字经**本机 Windows 内置语音合成**（零下载）转成音频再发出去；有 ffmpeg 就转 mp3，没有就发 wav。⚠️ **当前形态是"音频文件"，不是微信语音条**：微信 PC 没有"把任意音频发成语音条"的接口（要真语音条得用虚拟声卡 + 录音按钮，属待评估项）。合成全程本机、合成内容不出网。控制台**「语音回复」面板**可以看**实测**引擎/声音状态、切开关与音色语速格式，并用「试听一句」在本机合成一条示例（**只合成、不发送**）。
- **自定义工具（声明式 HTTP，默认关）**：把 `.json` 清单丢进 `tools.d/`，在控制台「工具与插件」里**勾选**就能给模型用。**只发 HTTP、不执行本地代码**；域名白名单必填，内网/本机地址永远拒绝；参数必须是合法 JSON Schema；坏清单会在面板里逐条报出来（不静默）。**怎么写、怎么加：控制台 →「工具与插件」→「怎么加工具」有应用内引导（三步 + 可复制模板 + 一键生成模板文件 + 打开目录 + 排错对照）；离线说明另见 [`tools.d/README.md`](tools.d/README.md)（中英双语）**。同时开始统计**每个工具的调用次数**（内置与自定义都算），一眼看出哪些只是摆设。
- **微信接入**：监听目标群消息，被 @ 或命中关键词时回复；支持发送文字、引用、拍一拍、表情收藏/发送、朋友圈查看（部分为模拟真人操作，需微信界面配合）
- **人设系统**：内置角色库（游戏/动漫/名著/历史等人物，可筛选、按分排序）；应用任意人设为机器人；支持自定义角色卡
- **评分与补足**：角色卡五维模型评分（风格/贴合/一致/自然/完整，百分位精度）；模型补足（按角色原话重写，分数上升才保留）
- **记忆**：群成员印象自动记录；记忆页查看/修改/删除；支持关机时把本次对话总结为印象
- **学习**：金句种子库（收藏高热度话术）、行为档推荐（参与度+表情包档位）
- **工具集**：联网搜索、图片识别、多轮对话、消息发送队列、API 中转站支持（OpenAI 兼容任意厂商）
- **用量与计费**：控制台实时统计会话/token/成本（今日/周期/累计），每日明细日历；计费日志可勾选删除
- **检测中心**：代码检测（48 项，含依赖核对）、点击测试（环境/点击/微信界面自动化 55 项，全程序内完成、不碰鼠标）
- **控制台**：本地界面（端口 3210；双击「一键启动.exe」之后在**我们自己的窗口**里打开，不依赖浏览器），所有可调项目（API、模型、人设、行为、记忆、发送限制、联网搜索、界面设置等）均可在界面中调节并保存生效。内含**「媒体与语音」面板**（随机图 / 语音转文字 / 视频·文件·链接 三项能力的开关、**实测引擎状态**、空状态与缺失态提示，「测试引擎」按钮会当场跑一遍本机语音链路）与**「版本能力矩阵」面板**（微信版本 × 适配层版本的逐项实测状态 + 版本门）。

- **记忆图谱**：把群友印象与会话记忆画成可交互的图谱（本机生成、零 token），一眼看清谁和谁聊过什么。
- **本地模型（可选，这一档完全不出网）**：自动发现本机的 Ollama / LM Studio 等 OpenAI 兼容端点，填个地址就能跑本地模型——**选这一档时聊天内容一个字都不出网**；云 API 那一档才出网。出不出网由你选，面板按**你选的那一档**如实写。
- **B 站与视频理解**：能解析 B 站链接（标题/简介/字幕/音频），也能读群友发来的视频（抽帧识别，可选转写）。
- **AI 视频生成（可选）**：按群友的要求生成短视频发出。后端**不用你选**——程序会自己探本机在跑的 ComfyUI 一类服务，探到就用；想固定用某一个再手填。
- **上云接口（预留，交互已做全）**：把存档屏蔽名单、记忆备份推到**你自己的**服务器；带三态探测与两种鉴权形态，接口契约可直接发给对方。
- **反馈栏**：在控制台里直接填反馈（选类型、写内容、点提交），程序会自动把它送到开发者那边；一条通道都没配时**如实显示"已存在本机、还没发出去"**并给「补发」，不留假成功。

## 快速开始

### 安装与启动

1. 解压 `群相-在线包-<日期>.zip` 到任意目录（路径不要有中文与空格最好）；
2. 双击 **「一键启动.exe」**——自动：检查/下载 Python → 安装缺失依赖 → 环境自检 → 启动机器人并打开控制台；
3. 控制台在**我们自己的窗口**里自动打开（若没出现，再双击一次「一键启动.exe」；也可手动访问 `http://127.0.0.1:3210/` 并用日志里提示的口令登录）；
4. 首次使用：到「模型 API」页填 Base URL（默认 DeepSeek 官方 `https://api.deepseek.com/v1`）与 API Key →「测试 API 连通」→「保存」；
5. 到「微信」页点「检测群聊并勾选」选择要监听的群 →「保存设置」；
6. 顶栏点「恢复」开始监听。

> 日常使用请用「一键启动.exe」（图形启动器，双击即启）；关闭请用「一键关闭.exe」（结束机器人/看门狗/安装器等全部残留进程）；开机自启=管理员运行 `scripts\开机自启.bat`。

## 常用设置说明（控制台）

- **版本能力矩阵与版本门**：控制台新增「版本能力矩阵」页，列出当前「微信版本 × 适配层版本」下每个能力的实测状态。**没有实测记录的版本对，发送前会被版本门拦下**（默认暂停自动发送，避免升级微信后照旧跑出事）；点「本次允许发送」可临时放行——**只对本次运行有效、不写进配置，重启重新拦**。

- **历史兜底条数**（`store.past_floor_count`，默认 8，0=关闭）：时间窗（`store.past_window_min`，默认 30 分钟）之外**至少保留最近 N 条**，并插入「这些是更早的历史、不是本轮要回答的内容」的提醒。为什么需要：群里长时间静默后突然被触发时，只按时间窗取会一条历史都取不到（模型被误导成「第一次参与这个会话」）——兜底保证它永远看得到上文。

## 权限与红线（务必先读）

### 它需要哪些能力、用来做什么

| 能力 | 具体动作 | 用途 | 边界 |
|---|---|---|---|
| 读微信本地数据 | 读 `WeChat Files` 下的本地数据库（消息/联系人/群） | 判断"谁说了什么"、拼上下文 | **只读本机、只读你自己的账号**；不做云端同步 |
| 数据库解密密钥 | 从本机微信进程内存里读取密钥，用来解密上面那些库 | 上面的读取必需 | **密钥永不出网**：不写日志、不进诊断包、不上传任何服务器 |
| 模拟操作微信 | 以后台消息注入为主（投窗口消息，不动鼠标；**可能短暂置前（2026-09-18 本机实测：发文字约 1 秒｜切会话 3~7 秒｜切会话失败重试可达约 15 秒），随后自动还回**）；必要时 UIA / 真实键鼠兜底（真鼠标兜底默认关，需显式开启） | 发消息、引用、拍一拍、朋友圈等 | **不注入 DLL、不 hook、不写微信进程内存、不改微信文件、不装驱动** |
| 本地控制台 | `http://127.0.0.1:3210`，需访问口令；**口令为空时拒绝一切请求** | 配置与监控 | **只绑回环**；`server.host` 写成别的地址会被强制改回 `127.0.0.1` |
| 出网 | 只发给你自己配置的模型 API（以及可选的搜索接口） | 生成回复 | 发送前本地脱敏（手机号/身份证/银行卡/地址），只送本轮必要片段 |
| 出网（随机图·在线图源） | 只在 `image_reply.mode=api/online` 时访问公开图源接口 | 取一张图再发 | **SSRF 闸门默认全开**：图源指向内网/环回/链路本地地址一律拒绝；只有自建本机图库服务才需要开 `security.allow_private_image_hosts`（**故意不做控制台开关**，要放开请手改 `config.json`） |
| 语音转文字 | 读本机微信语音文件（`.silk`）→ 本地解码 → **Windows 内置识别** | 让机器人"听懂"语音消息 | **音频不出网、不落云**；解码器 `pilk` 是**可选第三方依赖（GPL-3.0，不随本项目分发，需自行 `pip install pilk`）**，不用它就只是"不支持语音"而不是报错 |

### 我们不做的事（红线，写死在代码与自检里）

1. **完全开源（MIT）**：你拿到的就是全部源码，每一行都能自己审——不含闭源组件、不含"装机即用"的成品分发包，也没有任何需要联网校验的授权环节；
2. **不做营销群发**：默认带任务层闸门——同一内容在短时间内发给多个不同会话会被判定为群发并拦下；
3. **不做群控 / 加粉 / 自动换号 / 代理池 / 绕过风控**，也不写这类教程（这是"专门性"与"规避性"的分界线）；
4. **不读群成员列表、不导出他人数据**：群里其他人的信息不落库、不外传；
5. **不把 AI 回复伪装成真人**：用第三方模型时请保留可识别的标识（建议在会话固定位置标注，不必逐条加）；
6. **不上传任何来自微信的数据或密钥、不采集设备指纹**（对照：某些同类工具会把你的微信数据库密钥派生物上传到它自己的服务器做授权校验，我们不这么做）。
