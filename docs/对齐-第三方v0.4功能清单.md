## 二、本轮已补齐的缺口

### 22 · 大图自动压缩（`agent/img_compress.py`）
- **做什么**：发送前把过大的图片压到"能发出去又不太糊"——按最长边与文件大小双阈值，等比缩放 + 重编码；压完仍超限就再降一档质量；实在压不动（如已经是小尺寸高质量 PNG）就原样发并在回执里说明。
- **开关与参数**（进 `config.py` 默认段 + 控制台「媒体与语音」面板）：`send.image_compress.enabled`（默认开）/ `max_mb` / `max_px` / `quality`。
- **判据**：`scripts/img_compress_selftest.py`——大图必缩（最长边 ≤ 上限、字节数下降、宽高比保持 ±2%）、小图不动（字节级不变）、关掉开关不动、压缩失败时**回退原图**且回执如实说明（fail-open 于"发送"、fail-closed 于"静默"）。
