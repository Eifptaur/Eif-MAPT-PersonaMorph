## 二、本轮已补齐的缺口

### 22 · 大图自动压缩（`agent/img_compress.py`）
- **做什么**：发送前把过大的图片压到"能发出去又不太糊"——按最长边与文件大小双阈值，等比缩放 + 重编码；压完仍超限就再降一档质量；实在压不动（如已经是小尺寸高质量 PNG）就原样发并在回执里说明。
- **开关与参数**（进 `config.py` 默认段 + 控制台「媒体与语音」面板）：`send.image_compress.enabled`（默认开）/ `max_mb` / `max_px` / `quality`。
- **判据**：`scripts/img_compress_selftest.py`——大图必缩（最长边 ≤ 上限、字节数下降、宽高比保持 ±2%）、小图不动（字节级不变）、关掉开关不动、压缩失败时**回退原图**且回执如实说明（fail-open 于"发送"、fail-closed 于"静默"）。

## 三、缺口排期（按"能不能独立做完 + 收益"排序）

1. **单实例锁（bot 侧）**——小、清晰、可判据（命名互斥体 + 二次启动给明确提示）
2. **撤回后剔除上下文**——中等，收益直接（避免"用户已撤回的内容被模型引用"）
3. **备选模型逐个重试**——中等，动 `llm.py` 调用点
4. **改成"改完即生效 + 撤销修改"**——控制台交互改造（要动 `data-cfg` 保存链路）
5. **指令禁言 / 峰谷映射 / 固定 4 档**——三件同属"响应等级"族，一起做
6. **计时闹钟 / 节假日问候**——两个新工具 + 提示词规则（要防"定时群发"红线：只允许被动或显式开启）
7. **系统提示词编辑**——控制台加一个可编辑区 + 落盘 + 生效链路
8. **按会话/按条屏蔽存档消息**——中等，动 session 存储 + 控制台
9. **图/文/视频分流选模型 + 视频读取**——大，视频读取＝抽帧 + ASR（见 `docs/设计-群友要图-生图链条.md` 同源思路）
10. **上云三件（人设/屏蔽名单）**——**需要你先拍板**（要不要服务器、谁的服务器、隐私口径）
