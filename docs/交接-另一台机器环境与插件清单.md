# 交接：另一台机器（Windows 用户 = Administrator）的环境现状 + 要装的插件全清单

> 2026-09-14 写。用途：把这台机器（ptmou）上跑着的 DSH 环境，按同一份清单在那台机器上立起来。
> 事实来源：本机 `~/.dsh/profiles/web/package.json` 与 `cordis.patch.yml` 实读；那台机器的状态来自你发的两张截图 + 本机复现。

## 0. 一句话

那台机器现在的问题是 **DSH 的 `web` profile 没被建出来**（`%USERPROFILE%\.dsh\profiles\web` 不存在），所以自检里「Profile 清单 / 依赖状态 / 组合校验 / 安全网 guard」全红，点安装 guard 会弹「命令退出码是 0，但**回读不到包装**」——那是**诚实的回读闸**在说真话，不是包坏了。**先把 profile 建出来，再装插件。**

## 1. 那台机器当前状态（实测项已注明）

| 项 | 状态 | 说明 |
|---|---|---|
| 便携 Node | ✅ 已装 | `%LOCALAPPDATA%\DSH\node\node.exe`（**v22.11.0**，启动器自己下的）。**不在系统 PATH** ⇒ 普通命令行里敲 `node`/`npm` 用不了；启动器只给**自己进程**注入 PATH |
| `dsh.cmd` | ✅ 在 PATH | 启动器自检那一行是 ✔ |
| `profiles\web` | ❌ 不存在 | 依赖 / lockfile / node_modules / 组合校验 全红都是它的**下游** |
| `config.json` 的 `dshHome` | ⚠️ 疑似指向本机路径 | 若还写着 `C:\Users\ptmou\.dsh`（从本机拷过去的），启动器会一直读一个不存在的家目录，而 CLI 把东西装进 Administrator 家 ⇒ **"装了但回读不到"** |

## 2. 先做这三步（装插件的前置）

1. **改家目录**：打开启动器目录的 `config.json`，把 `"dshHome": "…"` 这**一整行删掉**（或改成 `"C:\\Users\\Administrator\\.dsh"`）。
2. **让它把 profile 建出来**（本机已实测：任何 `--profile` 命令都会自动初始化 profile 并打印 `initialized profile web at …`）：
   ```powershell
   dsh plugin --profile web list
   ```
   期望：打印 `dsh: initialized profile web at <家目录>\profiles\web`，并生成 `package.json` / `pnpm-workspace.yaml` / `cordis.patch.yml`。
3. **回启动器点「开始自检」**：`Profile 清单` 应转绿；如需要再点一次「一键安装 DSH」。

> 💡 用 **Agent启动器-2026.09.14.384**（或更新的）最省事：它修掉了"CLI 子进程与回读校验不是同一个家目录"这个缺陷（本机复现 → 修复 → 判据 `check-dshome634` 11/0，仓库提交 `738779d`）。384 之前的包都有这个毛病。

## 4. profile 配置（`%USERPROFILE%\.dsh\profiles\web\cordis.patch.yml`，四段，别漏）

1. **`system-prompt`**：`includeRuntimeContext: true` + `persona:`（本机那份硬规则，可整段拷过去）
2. **`dsh-phoenix`**：`restartCmd` —— 路径要改成**那台机器**启动器的路径
3. **`meow-memory`**：`enabled: true` / `promptLang: 'zh'`
4. **`graph-memory`**：**必须显式配抽取模型**，否则抽取永远卡住：
   ```yaml
   - id: graph-memory
     config:
       llmProvider: deepseek-official
       llmModel: deepseek-flash
   ```
   本机实测不配的错误原文：`[graph-memory] configure llmProvider/llmModel for extraction; session model is not used`

## 6. 已知坑（给那边的你）

1. **便携 Node 不在系统 PATH**：要用 `node` 就写全路径 `%LOCALAPPDATA%\DSH\node\node.exe`，或把 `%LOCALAPPDATA%\DSH\node` 加进用户 PATH。
2. **`dshHome` 不一致 = "装了却回读不到"**（本轮修掉的缺陷；384 之前的包都有）。
3. **装完插件要重启 `dsh web`** 才生效；客户端半边（侧栏/设置面板）改完一样要重启 + 浏览器硬刷新。
4. 本机 DSH 版本＝`0.1.5-rc.1`；本机自研包＝`Eif-MAPT-skills 0.5.24`。
5. 装插件失败先看启动器自检里的「GitHub 可达性」与「组合校验」两行，再看 `~/.dsh/guard/logs/launcher.log`。
