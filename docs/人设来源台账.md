# 人设来源台账（第一手资料）

> 用途：用户口径「**你写的人设要尽量贴合原人设。你去网上找，不要自己胡编乱造，尽量拿第一手资源——
> 所谓第一手资源，就是角色真正说过的话、做过的事**」。本台账记录**每张新卡的一手出处**，
> 供复核与复查；它不进在线包（`docs/` 被 `pack_online.py` 排除）。
>
> 无一手出处的台词**必须**在卡里标注`（按其口吻）`，不许冒充原话。

## 两个可复用的第一手来源

| 来源 | 是什么 | 抓法 |
|---|---|---|
| 官方角色页 `bang-dream.bushimo.jp/character/<band>/<romaji>/` | 官方设定原文（性格/生日/喜好/乐队定位），WordPress 站，可直抓 | `_scratch/gbp_profile.py`：只取 `<p>` 正文与基础资料行，跳过导航页脚（省 token） |
| 黑白双翼 WS WIKI `wiki.biligame.com/wstcg/` | **卡面「台词 / 高罕台词」字段＝游戏内语音原文**（日文） | 卡组页 → 卡页链接 → 逐页 HTML 抓 `<td>台词</td><td>值</td>`（`_scratch/ws_set_quotes.py`）。⚠️ `api.php` 连打会被限流（HTTP 567）；普通页面抓取可用，但也要留间隔 |
