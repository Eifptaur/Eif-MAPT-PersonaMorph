# 设计 · 群友要图 → 模型自己挑生图工具把图生成出来

> 用户 2026-09-13 原话：「**能不能让模型按照群友的要求用工具找那个生图软件生成群友需要的图？
> 除了不碰红线，其他都可以。你把相关的链条做好，把相关的东西都设计好。**」
> 定位：这是「A 随机二次元图」（从图源挑一张）的下一步——从**挑图**升级到**按需求生成图**。

## 1 · 链条（七段，每段都有机械判据）

| 段 | 做什么 | 判据（可自动跑） |
|---|---|---|
| ① 触发 | 群友在群里要图 → 模型在对话里决定调工具（默认**被动触发**；`trigger_mode=on_request/sometimes/off`） | 提示词里工具描述存在 + `trigger_mode` 真的改变 `prompt._scene_rules()` |
| ② 意图解析 | 从群友的话里抽出：要什么（主体）/风格/张数/尺寸/是否含人物 | `parse_image_intent("画只猫") → {subject:"猫", count:1, nsfw:False,…}` 单测 ≥12 例 |
| ③ 工具选择 | 按"可用性 + 适配度"排序挑一个生图后端；挑不到 ⇒ **明确说"我这会儿没有可用的生图工具"**（不许假装生成） | 假后端注入测试：无后端/后端报错/超时 三种情况都要给出人话原因 |
| ④ 生成 | 本地生图服务（ComfyUI/SD WebUI 等，走 HTTP）/ 在线 API（需 key，出网）/ 本地素材库兜底 | 生成产物落 `data/gen_images/<日期>/`，写台账 `data/gen_images/index.jsonl`（prompt、seed、模型、耗时、后端） |
| ⑤ 过滤 | **可插拔过滤链**：`safe_only`（默认开）→ r18/涉政/暴力 分类器 → 真人脸/换脸检测 → 侵权/水印/二维码 → 尺寸与损坏校验。**任一层不确定 ⇒ 不发**（fail-closed） | 每条过滤器一个正例 + 一个负例；"上游全挂"时整链判否（不是放行） |
| ⑥ 发送 | 复用现有发送链（投递优先 + 内容级身份闸 + 重复守卫 + DB 回读） | 复用 `send_image` 的既有判据；新增"生成图也要过身份闸"断言 |
| ⑦ 回执 | 控制台显示"谁要了什么图、用的是哪个后端、过滤结论、发没发出去" | `/api/status` 带 `image_gen` 段；面板逐行展示 |

## 2 · 红线（一条都不许破，写进代码注释 + 面板文案）

1. **不生成真人换脸/换身体**（`allow_real_face=false` 硬编码，无开关）。
2. **不出涉黄/涉政/暴恐**；`r18` 入口**根本不存在**（后端请求里不下发相关参数）。
3. **不确定就拒发**（过滤器超时 = 判否，不是放行）。
4. **不做"绝对安全"承诺**：README 与面板文案如实写"只降低概率"。
5. 生成内容**不外发到任何第三方**（除用户自己配的生图后端）；prompt 里先脱敏（手机号/身份证/地址/卡号）。
6. 群友要求本身违规（如"画个 xx 领导人"）⇒ **不生成、不回复该要求**，只在本机与控制台留痕。

## 3 · 控制台 UI（新增「群友要图」面板，照四件套：功能 + 判据 + UI 对象 + 应用内引导）

- 总开关（默认**关**）+ 触发条件（`on_request` 默认 / `sometimes` / `off`）
- 后端列表：`id | 类型(本地/在线) | 地址 | 状态(实测连通) | 最近一次耗时 | 调用次数`，可增删、可"测一下"
- 生成参数：尺寸档、最大张数/次、每日上限、超时
- **过滤链开关**（逐条可关但默认全开；关掉任何一条都要弹二次确认并写明后果）
- 风格白名单/黑名单（用户自填关键词）
- 「试生成一张（只生成不发）」按钮 + 结果缩略图 + 过滤结论
- 「引导」弹窗：这是什么 / 怎么接一个生图后端 / 红线是什么 / 失败怎么排查

## 4 · 给模型的提示词规则（`prompt.py` 里加一段，措辞要短）

```
群友要图时：先判断他要什么（主体/风格/张数），再调用 gen_image 工具生成；
生成后必须过过滤链，过滤不确定就**不发**并如实说明；生成失败要说明原因，禁止假装已生成。
不生成真人换脸、不生成涉黄涉政内容；这些要求本身也不要照做。
```

## 5 · 排期与依赖

- 前置：无（发送链、内容级身份闸、重复守卫都已就位）
- 第 1 件：`agent/image_gen.py`（后端抽象 + 意图解析 + 过滤链骨架）+ 单测（不需要真后端）
- 第 2 件：接一个真后端（**待用户拍板**：本地 ComfyUI / 在线 API / 两者都留）
- 第 3 件：控制台面板 + 引导 + `/api/status` 段 + 端点
- 第 4 件：工具描述接进 `tools.py` + `prompt.py`，跑"假后端端到端"
